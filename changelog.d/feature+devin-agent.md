Add Devin CLI as a first-class agent. Devin ships a Claude-Code-compatible hooks engine, so its native command hooks post the same stdin JSON shape Claude does and ride the existing hook socket with no new wire format. The deck installs its hooks into Devin's user config — `$XDG_CONFIG_HOME/devin/config.json` when set, else `~/.config/devin/config.json` — (merging, never clobbering, and never widening the file's permissions — malformed/JSONC content is backed up and the install errors rather than silently destroying the user's model, permissions, or MCP servers), auto-installs at daemon startup when `devin` is on `PATH`, and detects the Claude-import duplicate-events conflict with a one-line remedy. `dot-agent-deck hooks install --agent devin` and `dot-agent-deck hooks uninstall --agent devin` are the explicit CLI. Devin's badge colour is LightBlue.
